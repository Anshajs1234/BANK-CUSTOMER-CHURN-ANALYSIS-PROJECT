
# Bank Customer Churn Analysis


 
This is an End-to-End Bank Customer Churn Analysis project. Analyzed 20K+ customers data to find why customers are leaving the bank.

 What I Did
* **Loaded and Cleaned 20K+ customer data using Python Pandas and Performed EDA to Identify trends.**
* **Used Advanced Excel and SQL for Data Cleaning and Business Queries.**
* **Created data model and Built Interactive Power BI dashboard using DAX Functions.**
* **Analyzed Churn Patterns and suggested strategies to reduce churn by 14%.**

 Key Insights
* Overall Churn Rate: ~20%
* High Risk Region: Germany
* High Risk Age Group: 40-50 Years
* Female Customers and Inactive Members have higher churn

Tech Stack
* Advanced Excel
* Python - Pandas, Numpy
* SQL
* Power BI - Power Query, DAX

 Files in Repo
* `Bank_Churn.csv` - Dataset
* `analysis.ipynb` - Pandas & Numpy Code
* `queries.sql` - SQL Queries
